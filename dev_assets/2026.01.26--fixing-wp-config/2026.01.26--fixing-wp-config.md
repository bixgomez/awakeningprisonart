### 2026-01-26 14:30 - wp-config.php Refactored for Production

**Richard's Request:** Make wp-config.php production-ready and safe for version control.

**Issues Identified:**
1. Authentication salts were hardcoded and committed to git (security risk)
2. No production database configuration - only worked with DDEV
3. `.gitignore` had outdated paths (`/app/public/` instead of `/web/`)
4. File had `#ddev-generated` comment risking DDEV overwriting changes

**Changes Made:**

1. **Refactored `web/wp-config.php`:**
   - Removed hardcoded salts - now uses environment variables with safe local fallbacks
   - Added production database settings via environment variables (DB_NAME, DB_USER, DB_PASSWORD, DB_HOST)
   - Added WP_HOME/WP_SITEURL support via environment variables
   - Added production security settings (DISALLOW_FILE_EDIT, FORCE_SSL_ADMIN)
   - Set WP_DEBUG to false for production (configurable via env var)
   - Changed DB_CHARSET to utf8mb4 (better Unicode support)
   - Removed `#ddev-generated` comment to prevent DDEV from overwriting
   - Maintains full DDEV compatibility for local development

2. **Updated `.gitignore`:**
   - Fixed all paths from `/app/public/` to `/web/`
   - Added `/web/wp-config-ddev.php` to ignore list (DDEV-generated file)

**Environment Variables Required on Production (Linode):**
```
DB_NAME=your_database_name
DB_USER=your_database_user
DB_PASSWORD=your_database_password
DB_HOST=localhost
WP_HOME=https://yourdomain.com
WP_SITEURL=https://yourdomain.com
AUTH_KEY=<generate at https://api.wordpress.org/secret-key/1.1/salt/>
SECURE_AUTH_KEY=<generate>
LOGGED_IN_KEY=<generate>
NONCE_KEY=<generate>
AUTH_SALT=<generate>
SECURE_AUTH_SALT=<generate>
LOGGED_IN_SALT=<generate>
NONCE_SALT=<generate>
```

### 2026-01-26 14:45 - Refactored to Use Separate Environment Files

**Richard's Feedback:** The inline conditional approach was messy. Also has a local Linux server in addition to DDEV and Linode.

**Refactored Approach:**
- `wp-config.php` - Clean main config with only universal settings
- `wp-config-ddev.php` - DDEV auto-generated (already exists)
- `wp-config-env.php` - Single gitignored file to create on each non-DDEV server

**Changes Made:**
1. Simplified `web/wp-config.php`:
   - Removed all inline conditionals
   - Loads environment config based on detection order:
     1. DDEV (via IS_DDEV_PROJECT env var)
     2. wp-config-env.php (for any other server)
   - Only contains universal settings (DB_CHARSET, DB_COLLATE, table_prefix)
   - Dies gracefully if no environment config found

2. Updated `.gitignore`:
   - Added `/web/wp-config-env.php` to ignore list

3. Created template file:
   - `dev_assets/2026.01.26--fixing-wp-config/wp-config-env.template.php`
   - Ready to copy to each server and customize
   - Includes all necessary settings with comments

**Deployment Steps:**
1. Copy `wp-config-env.template.php` to each server as `web/wp-config-env.php`
2. Fill in server-specific values (database, URLs, fresh salts)
3. Each server can have different debug settings, memory limits, etc.
